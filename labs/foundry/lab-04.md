# Add tools to an agent

Follow your instructor's approved tool configuration. Enable only the tools
needed for the exercise and use least-privilege access.

- [ ] Review the available tools in the assigned Foundry project.
- [ ] Add the instructor-selected tool to your agent.
- [ ] Test the tool with an input that does not change or delete resources.
- [ ] Confirm the agent explains the tool result clearly.
