# Explore models in Foundry Toolkit

Open VS Code and select the Microsoft Foundry Toolkit icon. Sign in only with
the account and resources supplied by your instructor.

- [ ] Open the model catalog.
- [ ] Review the model card and deployment options for an instructor-selected model.
- [ ] Record the model name and region allowed for the course.
- [ ] If a course deployment is available, test it with a short, non-sensitive prompt.
