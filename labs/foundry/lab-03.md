# Build your first Foundry agent

Use the course project or sandbox provided by your instructor. Do not create
resources in an unapproved subscription.

- [ ] Open the assigned Foundry project in Microsoft Foundry Toolkit.
- [ ] Create an agent with a clear name and concise instructions.
- [ ] Test the agent with at least three representative prompts.
- [ ] Refine its instructions based on observed behavior.
